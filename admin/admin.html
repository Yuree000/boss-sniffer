🔧 高级 / 调试设置

沟通页 autoMark 点击时序

autoMark 用 chrome.debugger 派发鼠标事件点「不合适」按钮。「鼠标移到按钮上」到「按下」之间会等一小段随机时间(拟人 hover),让 BOSS 把它当真人 click 接受。 低于 30ms 可能被 BOSS 业务拒绝(v0.24.10 试过 0ms,出现概率性 click miss); 过高(> 200ms) 视觉上明显卡顿且可能撞 BOSS hover 二级菜单。建议保持默认 30-110ms。

每次 autoMark 真点击时,mouseMoved → mousePressed 之间随机等待 [下限, 上限] 毫秒。默认 30-110ms(对齐 lib/sayHi.js 推荐页打招呼时序,多年稳定)。

⚠️ 危险操作（开发调试用）

普通使用不需要这里的操作。HR 想"重新开始"直接点 sidepanel 的 [开始本轮]，会自动清空当前轮候选人评估。下面按钮供开发调试时彻底重置 IndexedDB。

清空评估：只清 evaluations 表（看板漏斗 / JD 分析 / 趋势 / 候选人记录 全部清空，sayhi 招呼历史 + 抓包数据保留）。
清空全部：清 captures + evaluations + events 三个表（看板所有数据归零，sayhi_pool / 话术 / JD 模板保留）。
两个操作都不可撤销。点击后需要二次 + 三次确认。

大模型配置教程

        
      

      

        

          
DeepSeek

          
协议选择 OpenAI Compatible，Base URL 填 https://api.deepseek.com，模型可填 deepseek-chat 或 deepseek-reasoner，鉴权方式选 Bearer Token。

        

        

          
通义千问 / DashScope

          
协议选择 OpenAI Compatible，Base URL 通常填兼容模式地址，模型可填 qwen-plus 或 qwen-turbo，鉴权方式选 Bearer Token。

        

        

          
Kimi

          
协议选择 OpenAI Compatible，Base URL 填 Kimi 的 OpenAI 兼容接口地址，模型可填 moonshot-v1-8k，鉴权方式选 Bearer Token。

        

        

          
Claude / Anthropic

          
协议选择 Anthropic Messages，Base URL 填 https://api.anthropic.com，模型填 Claude 模型名，鉴权方式选 x-api-key。

        

        

          
自定义兼容接口

          
OneAPI、OpenRouter 或公司代理如果兼容 OpenAI Chat Completions，协议选 OpenAI Compatible，Base URL 填到服务前缀即可；保存或测试时浏览器会请求该域名访问权限。
